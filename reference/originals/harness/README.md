# MacSoul GPT-6 Codex Harness

A 7-day implementation harness for building MacSoul v0.1 with Codex/Claude Code while keeping scope, progress, quality, and performance under control.

## Start
1. Put this entire folder at the root of the MacSoul Git repository.
2. Use a current Codex build/account that exposes the GPT-6 family models available to you.
3. Start Codex in the repository root.
4. Tell it: `Read prompts/KICKOFF.md and execute it.`
5. Each following day: `Read prompts/DAY-0N.md and execute it.`

## What makes this different
- design is locked before implementation
- 7 explicit daily plans with acceptance points
- mandatory daily progress reports
- automatic catch-up/recovery when a day slips
- GPT-6 family routing: Sol main implementation + Astra gates + Luna focused workers
- no quality shortcuts to recover schedule
- adaptive system-monitor sampling and strict performance budget

See `MANIFEST.md` for file roles.
