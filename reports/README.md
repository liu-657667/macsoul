# Daily Reports

Create/update one report per sprint day. Do not create prose-only status with no evidence.

Template:
```markdown
# Day N Report
Date:
Schedule state: GREEN/YELLOW/RED
Planned points:
Accepted points:
Completion:

## Completed
- task — evidence / acceptance

## Not completed
- task — P0/P1/P2 — reason

## Verification
- `command` → PASS/FAIL
- manual checks

## Performance / privacy
- observations

## Bugs / risks
- severity + owner/action

## Carry-over
- exact tasks and priority

## Scope changes
- cut/deferred items with reason

## Next day plan
1. carry-over P0 first
2. current-day P0
3. P1 if capacity
```
